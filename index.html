Projects

ACE (Adaptive Content Engine)

The Adaptive Content Engine (ACE) is a reinforcement learning–driven VR training system that personalizes cybersecurity education. It uses PPO and AIRL models to dynamically adjust challenge difficulty based on player performance, improving both engagement and learning efficiency.

Unity · PyTorch · TensorFlow · Reinforcement Learning

SAGE

SAGE (Student-Focused Adaptive Guidance Engine) is an intelligent tutoring framework that enforces instructor-regulated learning through a three-layer Safety Gatekeeper — role-based, attribute-based, and cognitive access control — built on a knowledge graph of learner state and curricular content.

Python · Knowledge Graphs · Access Control · LLMs
